Built around real work

Useful first. Impressive second.

GST Pragyan is intended to feel like a capable desk assistant: it helps organise information, exposes differences and gives you the references to check the answer. It does not replace professional judgement or statutory verification.

◎

Traceable

Prefer source columns, invoice-level details and visible calculations over unexplained scores.

⌂

Local-first

The desktop workflow is designed around files on your own computer rather than requiring your return data to be uploaded to a service.

!

Human in the loop

A discrepancy is a prompt to investigate, not a conclusion. The person reviewing the case remains in control.

Questions & corrections

Help make the reference better.

If you find a calculation, date or reference that needs correction, send the period, the figure shown and the provision you expected. Please do not send real taxpayer return data.
