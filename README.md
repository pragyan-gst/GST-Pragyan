# GST Pragyan

GST Pragyan is a practical GST workbench website centred on the offline desktop analysis workflow.

## Website structure
- `index.html` — product-led home page, task launcher, workflow, charts, desktop-tool positioning and everyday GST utilities.
- `compliance.html` — calculators and detailed GST reference tables, including Sections 73, 74 and 74A limitation timelines.
- `privacy.html` — privacy and local-first data handling information.
- `assets/` — GST Pragyan branding assets.

## Design direction
The site intentionally avoids audience labels such as “Who it's for”. Visitors are instead invited to start with the GST task they need to complete: merge, compare, analyse, calculate or check the law.

The desktop tool is the central product story. The reference pages support the workflow with calculators, charts, due dates, historical changes, ITC, reversals, RCM, e-Way Bill and limitation references.
