# GST Pragyan

GST Pragyan is a practical GST workbench website centred on the offline desktop analysis workflow.

## Website structure
- `index.html` - product-led home page, task launcher, workflow, charts, desktop-tool positioning and everyday GST utilities.
- `compliance.html` - calculators and detailed GST reference tables, including Sections 73, 74 and 74A limitation timelines.
- `privacy.html` - privacy and local-first data handling information.
- `assets/` - GST Pragyan branding assets.

## Design direction
The site presents the current product workflow directly: merge return data, check sources, scrutinise, inspect evidence, calculate, and verify the law. It also keeps the charts and browser calculators close to the desktop workflow.

The desktop tool is the central product story. The reference pages support the workflow with calculators, charts, due dates, historical changes, ITC, reversals, RCM, e-Way Bill and limitation references. The current desktop workflow also includes source-aware scrutiny, Parameter Evidence Viewer, paid/reversed/net reconciliation, head-wise interest, and single-return-type multi-year merging.
